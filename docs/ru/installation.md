# Установка

## Через PyPI (рекомендуется)

```bash
pip install cdriv
```

Обновление до последней версии:

```bash
pip install --upgrade cdriv
```

## Из исходного кода

```bash
git clone https://github.com/Draken119/cdriv.git
cd cdriv
pip install .
```

## Проверка установки

```bash
pip show cdriv
```

Ожидаемый результат:

```
Name: cdriv
Version: 1.0.2
Summary: Control Chromium via ChromeDriver on Termux...
```

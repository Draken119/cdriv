# Installation

## Via PyPI (recommended)

```bash
pip install cdriv
```

Upgrade to the latest version:

```bash
pip install --upgrade cdriv
```

## From Source

```bash
git clone https://github.com/Draken119/cdriv.git
cd cdriv
pip install .
```

## Verify Installation

```bash
pip show cdriv
```

Expected output:

```
Name: cdriv
Version: 1.0.2
Summary: Control Chromium via ChromeDriver on Termux...
```

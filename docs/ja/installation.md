# インストール

## PyPI 経由 (推奨)

```bash
pip install cdriv
```

最新バージョンにアップグレードする場合:

```bash
pip install --upgrade cdriv
```

## ソースからインストール

```bash
git clone https://github.com/Draken119/cdriv.git
cd cdriv
pip install .
```

## インストールの確認

```bash
pip show cdriv
```

期待される出力:

```
Name: cdriv
Version: 1.0.2
Summary: Control Chromium via ChromeDriver on Termux...
```

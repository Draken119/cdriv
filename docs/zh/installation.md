# 安装

## 通过 PyPI 安装（推荐）

```bash
pip install cdriv
```

升级到最新版本：

```bash
pip install --upgrade cdriv
```

## 从源码安装

```bash
git clone https://github.com/Draken119/cdriv.git
cd cdriv
pip install .
```

## 验证安装

```bash
pip show cdriv
```

预期输出：

```
Name: cdriv
Version: 1.0.2
Summary: Control Chromium via ChromeDriver on Termux...
```
